# Operação, monitoramento e recuperação

## Itens a preparar antes do piloto

- Alertas de orçamento por projeto Firebase.
- Alertas de erros e falhas de backend.
- Monitoramento de uso do Realtime Database e Storage.
- Registro de versão/commit de cada APK distribuído.
- Backup automático do banco de testes.
- Procedimento documentado de restauração.
- Política de retenção de fotos, localização e logs.
- Canal para incidentes e suporte.

## Custos

- Separar orçamento de desenvolvimento, piloto e produção.
- Definir limites e alertas por projeto.
- Lembrar que alertas de orçamento não bloqueiam automaticamente gastos.
- Não ativar faturamento ou recursos pagos sem aprovação expressa.
